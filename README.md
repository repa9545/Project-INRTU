# Консольная игра "Змейка" (Snake Game)
Семестровый проект по введению в профессиональную деятельность на языке C++
Классическая аркадная игра "Змейка" реализованная для консоли Windows без использования графики.

## Возможности игры
- Плавное движение и отрисовка игрового поля без мерцания экрана
- Управление в реальном времени без ожидания нажатия Enter
- Подсчёт очков и увеличение длины змейки при сборе еды
- Выбор уровня сложности (скорости игры)
- сохранение таблицы лучших рекордов текстовый файл

## Управление 
- 'W' / 'Ц' / '↑' — движение вверх
- 'S' / 'Ы' / '↓' — движение вниз
- 'D' / 'В' / '→' — движение вправо
- 'A' / 'Ф' / '←' — движение влево
- 'P' — пауза
- 'X' — выход из игры
